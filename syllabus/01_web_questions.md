## Ques2.
Problem Statement:
Create a webPage that allow user to manage employee task
The page contians:
  - an input box to enter an employee name
  - an input box to enter a task
  - a button Add task
  - A table displaying all added tasks
  - a acomplete button for each task
  - a delete button for each task
 
Requirement:
  1. When user click Add Task
  	- read the employee name and task
  	- if either field is empty, display an error message
  	- Otherwise, add the task to table
  2. Each task should initallly have the status: PENDING
  3. When the comleete button is clicked
  	- change the status from pending to completed
  	- disable the complete button
  4. When delete button is cliecked:
  	- remove the task from the table
  5. Display the total number of task in the table
