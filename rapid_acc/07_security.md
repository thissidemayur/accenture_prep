# Accenture Security — 40 High-Return MCQs

**Basis:** Your 10 supplied Security MCQs, expanded into non-repetitive placement-focused questions.

## 40 MCQs

## 1. IP Spoofing

A packet is sent with a forged source IP address so the sender's real address is hidden or traffic rules are bypassed. What attack is this?

A) Man-in-the-Middle
B) IP Spoofing
C) ARP Poisoning
D) SQL Injection

**Answer: B**

**Why:** IP spoofing falsifies the source IP address.

## 2. Man-in-the-Middle

An attacker secretly intercepts communication between a user and a server and may modify the traffic. What attack is this?

A) Phishing
B) Man-in-the-Middle
C) DoS
D) Brute Force

**Answer: B**

**Why:** A MITM attacker positions themselves between communicating parties.

## 3. ARP Poisoning

An attacker sends forged ARP messages so a victim associates the attacker's MAC address with a trusted IP address. What is this?

A) ARP Poisoning
B) IP Spoofing
C) DNS Hijacking
D) Packet Sniffing

**Answer: A**

**Why:** ARP poisoning corrupts local ARP mappings and can redirect LAN traffic.

## 4. DNS Spoofing

A user enters a legitimate domain but receives a malicious IP address and is redirected to an attacker's site. What attack is this?

A) DNS Spoofing
B) MITM
C) XSS
D) SQL Injection

**Answer: A**

**Why:** DNS spoofing manipulates DNS resolution so a domain resolves to an attacker-controlled destination.

## 5. DoS

A web server becomes unavailable after receiving a huge volume of requests from one attacking source. What is this?

A) DoS
B) MITM
C) ARP Poisoning
D) SQL Injection

**Answer: A**

**Why:** A denial-of-service attack attempts to make a service unavailable.

## 6. DDoS

Thousands of compromised devices simultaneously flood a website with traffic. What is this?

A) DoS
B) DDoS
C) IP Spoofing
D) Phishing

**Answer: B**

**Why:** DDoS uses multiple distributed sources.

## 7. Phishing

An employee receives a convincing email linking to a fake company login page designed to steal credentials. What attack is this?

A) SQL Injection
B) Phishing
C) ARP Poisoning
D) XSS

**Answer: B**

**Why:** Phishing uses deceptive communication to trick victims into revealing information or taking harmful actions.

## 8. XSS

A vulnerable web application allows attacker-controlled JavaScript to execute in another user's browser. What attack is this?

A) SQL Injection
B) XSS
C) DoS
D) DNS Spoofing

**Answer: B**

**Why:** Cross-Site Scripting injects executable script into web content viewed by other users.

## 9. SQL Injection

A malicious user enters crafted SQL syntax into an application input field to manipulate database queries. What is this?

A) XSS
B) SQL Injection
C) Phishing
D) MITM

**Answer: B**

**Why:** SQL injection targets database queries through unsafe application input handling.

## 10. Packet Sniffing

An attacker passively captures network packets to inspect unencrypted usernames, passwords and other traffic. What is this?

A) Packet Sniffing
B) DDoS
C) IP Spoofing
D) DNS Spoofing

**Answer: A**

**Why:** Packet sniffing captures and analyzes network traffic.

## 11. Credential Stuffing

An attacker uses username/password pairs leaked from another website to log into many accounts. What attack is this?

A) Credential Stuffing
B) XSS
C) ARP Poisoning
D) DNS Spoofing

**Answer: A**

**Why:** Credential stuffing reuses previously leaked credentials against other services.

## 12. Brute Force

An attacker repeatedly tries different password combinations until a valid password is found. What is this?

A) Brute Force
B) DNS Spoofing
C) Packet Sniffing
D) MITM

**Answer: A**

**Why:** Brute-force attacks systematically try many possible credentials.

## 13. Password Spraying

An attacker tries one common password against many different user accounts instead of many passwords against one account. What is this?

A) Password Spraying
B) SQL Injection
C) XSS
D) ARP Poisoning

**Answer: A**

**Why:** Password spraying reduces the chance of triggering per-account lockout mechanisms.

## 14. Session Hijacking

An attacker obtains a victim's valid session identifier and uses it to impersonate the victim. What attack is this?

A) Session Hijacking
B) DDoS
C) DNS Spoofing
D) SQL Injection

**Answer: A**

**Why:** Session hijacking abuses a valid authenticated session token.

## 15. Replay Attack

An attacker captures a valid authentication message and later retransmits it to gain access. What is this?

A) Replay Attack
B) DoS
C) XSS
D) ARP Poisoning

**Answer: A**

**Why:** Replay attacks reuse previously captured valid messages.

## 16. Evil Twin

An attacker creates a fake Wi-Fi access point with a name similar to a legitimate network to trick users into connecting. What is this?

A) Evil Twin
B) SQL Injection
C) DNSSEC
D) DoS

**Answer: A**

**Why:** An evil twin is a malicious rogue Wi-Fi access point impersonating a legitimate one.

## 17. Rogue Access Point

An unauthorized wireless access point is connected to a corporate network by an attacker. What is it called?

A) Rogue Access Point
B) DNS Server
C) Proxy Cache
D) Load Balancer

**Answer: A**

**Why:** A rogue AP is an unauthorized wireless access point.

## 18. Shoulder Surfing

An attacker watches a person enter a password at a public location. What attack is this?

A) Shoulder Surfing
B) SQL Injection
C) DDoS
D) ARP Poisoning

**Answer: A**

**Why:** Shoulder surfing obtains sensitive information by visually observing the victim.

## 19. Social Engineering

An attacker manipulates an employee psychologically into revealing confidential information. What category does this belong to?

A) Social Engineering
B) Packet Fragmentation
C) NAT
D) DNS Resolution

**Answer: A**

**Why:** Social engineering exploits human behavior rather than a technical vulnerability.

## 20. Vishing

An attacker calls an employee pretending to be a bank or IT support agent and asks for credentials. What is this?

A) Vishing
B) XSS
C) ARP Poisoning
D) DDoS

**Answer: A**

**Why:** Vishing is voice/telephone-based phishing.

## 21. Smishing

A victim receives a fraudulent SMS containing a malicious link designed to steal credentials. What is this?

A) Smishing
B) SQL Injection
C) IP Spoofing
D) MITM

**Answer: A**

**Why:** Smishing is phishing delivered through SMS/text messages.

## 22. Ransomware

Malware encrypts an organization's files and demands payment for recovery. What type of attack is this?

A) Ransomware
B) DNS Spoofing
C) ARP Poisoning
D) Packet Sniffing

**Answer: A**

**Why:** Ransomware denies access to data, commonly by encryption, and demands payment.

## 23. Trojan

A malicious program is disguised as legitimate software so the victim installs it. What is this commonly called?

A) Trojan
B) Firewall
C) VPN
D) IDS

**Answer: A**

**Why:** A Trojan disguises malicious functionality as legitimate software.

## 24. Worm

Malware automatically spreads from system to system without requiring the user to manually install it on every target. What is this?

A) Worm
B) Trojan
C) Phishing
D) XSS

**Answer: A**

**Why:** A worm can self-propagate across systems or networks.

## 25. Botnet

A large collection of compromised devices is remotely controlled by an attacker and used to launch attacks. What is this network called?

A) Botnet
B) VLAN
C) VPN
D) CDN

**Answer: A**

**Why:** A botnet is a network of compromised devices under attacker control.

## 26. Privilege Escalation

A compromised normal user account is used to obtain administrator-level permissions. What attack is this?

A) Privilege Escalation
B) DNS Spoofing
C) Packet Sniffing
D) DoS

**Answer: A**

**Why:** Privilege escalation increases the attacker's permissions beyond the initial access level.

## 27. Zero-Day

An attacker exploits a software vulnerability before a fix is available or before defenders have had an opportunity to patch it. What is this commonly called?

A) Zero-Day Exploitation
B) ARP Poisoning
C) Password Spraying
D) NAT

**Answer: A**

**Why:** A zero-day refers to a vulnerability/exploitation for which no effective patch was available at the relevant time.

## 28. Port Scanning

An attacker probes many TCP/UDP ports on a server to discover which services are listening. What activity is this?

A) Port Scanning
B) Phishing
C) XSS
D) DNS Spoofing

**Answer: A**

**Why:** Port scanning is used to identify exposed services and open ports.

## 29. Vulnerability Scanning

A security team automatically checks systems for known vulnerabilities and missing patches. What activity is this?

A) Vulnerability Scanning
B) DDoS
C) MITM
D) Session Hijacking

**Answer: A**

**Why:** Vulnerability scanners identify known security weaknesses.

## 30. SQL Injection Prevention

Which approach is the standard defense against SQL injection in application code?

A) Parameterized queries/prepared statements
B) Base64 encoding user input
C) Disabling HTTPS
D) Increasing database size

**Answer: A**

**Why:** Parameterized queries separate SQL code from user-supplied data.

## 31. XSS Prevention

Which approach is a key defense against XSS when displaying untrusted data in HTML?

A) Context-appropriate output encoding
B) Disabling DNS
C) Using FTP
D) Increasing TCP timeout

**Answer: A**

**Why:** Output encoding prevents untrusted data from being interpreted as executable markup/script.

## 32. MITM Prevention

Which mechanism helps protect a web session from interception and modification in transit?

A) TLS with certificate validation
B) Plain HTTP
C) Telnet
D) Unencrypted FTP

**Answer: A**

**Why:** TLS encrypts traffic and certificate validation helps authenticate the intended server.

## 33. ARP Poisoning Defense

Which control can help reduce ARP spoofing/poisoning risk on managed enterprise networks?

A) Dynamic ARP Inspection
B) DHCP only
C) FTP
D) SMTP

**Answer: A**

**Why:** Dynamic ARP Inspection validates ARP messages using trusted DHCP-snooping information on supported switches.

## 34. DDoS Defense

A public application needs protection against large-scale distributed traffic floods. Which control is directly relevant?

A) DDoS mitigation service
B) Local password policy only
C) ARP cache
D) Text editor

**Answer: A**

**Why:** DDoS mitigation services detect and absorb/filter attack traffic.

## 35. Least Privilege

An employee should receive only the permissions required for their job. Which security principle applies?

A) Least Privilege
B) Full Trust
C) Open Access
D) Anonymous Access

**Answer: A**

**Why:** Least privilege limits unnecessary permissions and reduces the impact of compromised accounts.

## 36. MFA

A user must provide a password plus a one-time code from an authenticator app. What control is this?

A) MFA
B) NAT
C) DNS Spoofing
D) Packet Sniffing

**Answer: A**

**Why:** Multi-factor authentication uses more than one authentication factor.

## 37. Security Patch

A vendor releases a fix for a known vulnerability and administrators install it on affected systems. What security action is this?

A) Security Patching
B) Packet Sniffing
C) IP Spoofing
D) DNS Hijacking

**Answer: A**

**Why:** Patching removes or mitigates known software vulnerabilities.

## 38. Defense in Depth

An organization uses firewalls, MFA, endpoint protection, network segmentation and monitoring rather than relying on one security control. What principle is this?

A) Defense in Depth
B) Single Point of Trust
C) Open Access
D) Port Forwarding

**Answer: A**

**Why:** Defense in depth uses multiple layers of controls so one failure does not expose everything.

## 39. Network Segmentation

A company separates its payment servers from general employee systems to limit lateral movement after a compromise. What security technique is this?

A) Network Segmentation
B) DNS Resolution
C) NAT only
D) Packet Fragmentation

**Answer: A**

**Why:** Segmentation limits communication paths and can reduce lateral movement.
